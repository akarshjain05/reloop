# Third-party software, services and assets

All application code in this repository was written for this project; it follows each library's public documentation. No starter template or boilerplate repository was used, and no datasets are bundled. Licenses below are as published by each project at the time of writing; **re-check before submission** (`pip-licenses` / `license-checker` will list the exact installed versions).
