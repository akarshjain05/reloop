# Data sources

Nothing in ReLoop presents invented numbers as facts. Data falls into five kinds, kept apart in the code and labeled in the UI.

## 1. Demo data (fictional)
| What | Where | Notes |
|---|---|---|
| People, buildings, organizations ("SVNIT Green Campus (Demo)", "Sunrise Heights Society (Demo)", "TechNova Office Park (Demo)"), six months of history, pickups, fraud cases, bin checks, challenges | `backend/app/services/seed.py` (deterministic, seed 42) | 4,828 documents, all `demo: true`. Names are random combinations of common Indian first/last names, not real people. Dates are generated relative to *today* so charts are never empty. |
| 8 recyclers around Surat | `backend/app/data/demo/recyclers.json` | **Fictional.** No real business, none officially authorised; "verified" means only *marked verified in the demo dataset* and is labeled that way. |
| Price catalog (type ranges, brand/condition factors, 14 named models) | `backend/app/data/demo/price_catalog.json` | Hand-curated placeholders. `is_live: false`, `source`, `updated` and a disclaimer travel with every estimate. |
| Sample photos | `frontend/public/samples/*.jpg` (generated by `scripts/make_sample_images.py`) | Original flat illustrations, not photographs. |

## 2. User-generated data
Photos (re-encoded, EXIF/GPS removed, stored privately with signed URLs), corrections, confirmations, pickup requests and addresses, bin checks, challenge joins. Predictions store the raw AI output **and** the user's correction (`ai_predictions`). Admin exports (CSV) contain this data; handle them accordingly.

## 3. Configured assumptions (placeholders to replace)
| File | Contents | Status |
|---|---|---|
| `backend/app/data/assumptions/impact_factors.yaml` | Typical weight, CO₂e per item, recovery score, material shares, base points per item type; expected category mix; collection-drive sizing | **Illustrative placeholders.** Laptop (1.8 kg, 6.4 kg CO₂e) comes from the project brief; the rest are rough, internally consistent guesses. Replace with cited values before any public environmental claim. |
| `backend/app/data/assumptions/scoring.yaml` | Points formula parameters, daily cap, tiers, ReLoop Score weights and targets, fraud thresholds | Design parameters, documented in ARCHITECTURE. |

Every impact response carries `assumptions_version`, `is_estimate: true` and a disclaimer; the UI repeats "illustrative estimate" next to every CO₂e figure.

## 4. External sources
**None are used at runtime.** The app makes no calls to third-party data APIs.

| Source | Status | Notes |
|---|---|---|
| CPCB list of authorised e-waste dismantlers/recyclers | **Not imported.** Intended future source for `recyclers`. | Published as state-wise PDFs of authorisations issued by state pollution control boards, so it needs digitising, geocoding (e.g. Amazon Location Service) and a freshness check. The recycler model already has `verification.{status, source, license_no, valid_until}` for it. Check the publisher's terms before reuse. |
| data.gov.in (government open datasets) | Not used | Listed on the hackathon data page. Check each dataset's licence before use. |
| Registry of Open Data on AWS, CPCB AQI, OpenAQ, NASA FIRMS, IMD, India WRIS | Not used | Air, water, weather, fire and satellite sources serve other tracks; they don't inform an e-waste handover loop. |
| Google Maps "Directions" links | Link only | Opens in the user's browser (new tab). No API key, no data fetched or stored by ReLoop. |
| Amazon Bedrock model | Runtime AI service | Default `us.amazon.nova-lite-v1:0`; model terms are Amazon's. Image content is sent to Bedrock for classification when `AI_PROVIDER=bedrock`. |

Libraries, fonts and icons are listed in [THIRD_PARTY.md](../THIRD_PARTY.md).

## 5. AI-generated estimates
| Output | Produced by | Safeguards |
|---|---|---|
| Item type, brand, condition, quantity, confidence, notes | `BedrockProvider` (or the deterministic mock in demo mode) | Strict JSON contract validated server-side; shown with a confidence bar and *AI estimate* label; the person confirms or corrects; correction stored. |
| Bin categories (`Scan My Waste`) | Same | Person confirms what they actually removed. |
| Agent rationale (two sentences) and Advisor recommendation text | Bedrock, from tool outputs / verified facts only | Prompts forbid invented numbers; verified facts are shown separately with sources; labeled *AI-generated recommendation*. |
| Resell/repair/recycle/donate decision | **Rules** (not an LLM) in `backend/app/services/actions.py` | Each recommendation carries its reason. |
| Value ranges, points, CO₂e, ReLoop Score, collection-gap sizing | Deterministic code reading the configured data above | Labeled as estimates; formulas documented. |
